## Bugs found and fixed (all live in prod, agent-chat v16)

1. **Grounding post-check nuked scam debunks.** Quoting the scammer's "$5,000" to warn
   about it was flagged as an "invented amount". Fix: quoting the user's own message
   (amounts, URLs, guarantee words) is never a violation — only model-originated
   claims are. Amounts compare numerically ("$5,000" == "$5000"); guarantee words
   compare by root ("guaranteeing" == "guaranteed"). Debunk markers
   (scam/red flag/too good/stay away/…) also exempt the guarantee rule.
2. **Model falsely claimed verified routes exist.** System prompt asserted route cards
   exist; DB has zero verified. Fix: prompt now injects the live verified count and
   instructs the model to say verification is underway when it's 0.
3. **Rate limiting** (from security audit): 60 replies/user/hour, verified 429 + 200 paths.

## Known gaps (not yet fixed)

  The verification engine (research loop workstream) is the critical path.
